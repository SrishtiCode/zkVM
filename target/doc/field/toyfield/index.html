ToyField — the finite field GF(97).

97 is prime, and 97 - 1 = 96 = 2^5 * 3, so the field has a 2-adic subgroup of size 2^5 = 32. That’s plenty of room for the toy domains (8–16 elements) the visualizers use, while every element stays a single two-digit number you can read at a glance in a trace table or FRI fold diagram.

This is the default field for the whole project. Goldilocks exists so “real mode” can show the same code path at production size.
