Expand description

A finite field with a large 2-adic multiplicative subgroup.

Implementors get + - * neg “for free” via the standard std::ops traits so field elements behave like any other numeric type in the rest of the codebase.

Required Associated Constants§

Source

const TWO_ADICITY: u32

log2 of the largest power-of-two subgroup of the multiplicative group, i.e. the largest k such that 2^k | (p - 1). FFTs of size up to 2^TWO_ADICITY are supported.

The field’s prime modulus, as a u64. Every field in this crate is prime-order, so this fully determines the field.

Source

Multiplicative inverse, or None for zero (which has none).

Source

fn primitive_root_of_unity() -> Self

A primitive 2^TWO_ADICITY-th root of unity: g such that g^(2^TWO_ADICITY) == 1 and no smaller power of two exponent works.

fn root_of_unity(log_n: u32) -> Self

A primitive 2^log_n-th root of unity, derived from Self::primitive_root_of_unity by repeated squaring.

This is the twiddle-factor generator every FFT/IFFT/LDE call in poly uses to build its evaluation domain.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
