field — finite field arithmetic (Phase 0).

This crate defines the Field trait, the single abstraction the rest of the pipeline (poly, air, fri, …) is built on top of, plus two concrete implementations:

  • toyfield::ToyField — arithmetic mod 97. Every element, every FFT twiddle factor, every FRI fold is small enough to print and read by eye. This is the field the visualizers use by default.
  • goldilocks::Goldilocks — the real 64-bit STARK-friendly field p = 2^64 - 2^32 + 1. Same trait, same code paths, “real mode.”

Both fields have high 2-adicity: p - 1 is divisible by a large power of two, which is exactly what FFT-based polynomial arithmetic (interpolation, low-degree extension, FRI) needs, since it repeatedly splits a domain in half.
